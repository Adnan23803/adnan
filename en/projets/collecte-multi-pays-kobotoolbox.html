KoboToolbox · XLSForm 2020–2024

Standardizing data collection across multiple countries.

A shared, multilingual and controllable system for consolidating data produced in different field contexts.

The project harmonized data collection and processing across Mali, Burkina Faso, the Democratic Republic of Congo and the Central African Republic while preserving each field context’s constraints.

Period
2020–2024
Coverage
Mali · Burkina Faso · DR Congo · Central African Republic
Role
System design, forms and data consolidation
Tools
KoboToolbox · XLSForm · API · Excel · Power Query

The challenge

Teams in several countries needed shared indicator definitions and comparable data. Language, connectivity and working-practice differences increased the risk of errors and manual consolidation.

The solution

I designed advanced KoboToolbox XLSForms with constraints, skip logic, consistency checks and multilingual labels. Submissions were then structured for a central repository and cross-site analysis.

Method

01
Harmonized variables

Identical indicator definitions and validation rules across all countries, so that data stays comparable from one site to the next.

02
Testing with field teams

Every form is tested by the field teams before deployment, to catch wording and translation ambiguities early.

03
Offline collection

Configured for areas with limited connectivity: local data entry, then deferred synchronization to the server.

04
Automated consolidation

Submissions retrieved and processed through API, Excel and Power Query rather than by hand-editing exports.

05
Documented system

Variables, rules and flows are documented so the system remains maintainable after the assignment ends.

Outcome

◆

Four capitals

A shared workflow deployed in Bamako, Ouagadougou, Kinshasa and Bangui.

◆

Consistent structure

The same data structure produced by every site.

◆

Cross-site comparison

Country-to-country analysis becomes possible without reprocessing.

◆

Multilingual system

Translated forms, usable in each field context.
